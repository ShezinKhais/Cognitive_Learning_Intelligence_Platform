# C.L.I.P. informational website

This static site introduces the project, demonstrates a sample checkpoint, and
provides guides for students, lecturers, and administrators. The sample
checkpoint runs in the browser with illustrative data.

Preview the site locally from the repository root.

```sh
python3 -m http.server 8001 --directory site
```

Open [the local website](http://localhost:8001/) or
[the local user guides](http://localhost:8001/guide.html). An editable
[Word copy of the guide](clip-user-guide.docx) is in the same directory.
